10 amazing things we learned you can do with Claude’s new Artifacts tool.

Ever since Llama 3.1's drop last week, we've seen a lot of benchmarks thrown around on X comparing it to ChatGPT and Claude's best models. Whether or not these benchmarks are reliable or accurate is TBD—it’s been less than a week since 3.1 hit the streets. 

One trend in the data did stand out, though: Claude 3.5 Sonnet is nearly always at the top of them (some examples: 1, 2, 3). 

This made us ask: So what can you actually do with Claude 3.5 Sonnet today? Surprisingly, a ton of stuff—especially if you use Claude’s new tool called Artifacts. 

Shout out to friend of The Neuron Allie K. Miller and her recent thread that collected all these demos! 

First, what are Artifacts? They're separate, standalone windows that appear to the right of your chat. Claude automatically creates them for self-contained content over 15 lines that you're likely to edit or reuse if you have the setting turned on (learn how to use them here). 

Now, let's dive into 10 mind-blowing things you can do with Claude 3.5 Sonnet:

  1. Document analysis: Allie created 3 interactive dashboards from 100 pages of Amazon shareholder reports in 46 seconds. (Pro tip: write “MAKE IT 100X MORE INTERACTIVE”) for wild results. (link)

  2. Simplify data visualization: Razia Aliani used Claude to analyze data, visualize it, and create simple presentations directly in the chat. (link)

  3. Build interactive dashboards: CJ transformed a pitch deck into an interactive dashboard for investors with a single prompt.  (link)

  4. Create a functional soundboard: Ammaar built an AI sound effects generator using the ElevenLabs API by pasting it in the API documentation. (link)

  5. Code up games: Allie coded a fully functional Mancala web app in 25 seconds using just one screenshot of game instructions. (link)

  6. Generate infographics and SVGs: Ethan Mollick created an infographic from a 78-page PDF and recreated a painting as an SVG. (link)

  7. Animate physics simulators: Rafal Wilinski dropped a 3D physics simulation using WebGL in one try. (link)

  8. Customize personal calendars: Sully Omar built a basic Google Calendar clone using Claude's Artifacts. (link)

  9. Create decision-making bots: Allie developed an interactive decision-making bot by feeding Claude massive amounts of data and preferences. (link).

Try to build something with Artifacts this week and send it our way! If you like it, click publish, and you can share it with anyone on the internet (or snap a screen capture and tag us on X).
