ChatGPT's Mac update quietly sets the stage for January's big “Operator” release (and by Operator, we mean “agent”).

If you missed yesterday’s story (and even if you read it), you might have missed this:

While January is a long time from now (AGES, in AI years), OpenAI just released two big updates to its desktop app that set the stage for what’s to come:

  1. ChatGPT for Windows is now available to everyone, with features like Alt + Space for quick access + companion windows to pick up where you left off.

  2. ChatGPT for MacOS can now “see” exactly what you see on your desktop, and help you do stuff within apps.

Video demo of how this works in action

For the Mac update (which is the really interesting one), ChatGPT's desktop app can now directly interact with apps on your screen.

For developers, this means ChatGPT can now read directly from:

  • VS Code (coding tool) and Xcode (Mac-app specific coding tool).

  • Terminal and iTerm (the interface for talking to your computer to run programs and commands).

  • Even basic text editors (like TextEdit, where you can write simple code or notes).

The best way to think of this update is as a test run for how ChatGPT will interact with your computer when it becomes a full-fledged agent in January. For now, it can only see these apps, but soon it’ll be able to act on your behalf.

Here’s how you can try it yourself:

  1. Download the Mac Desktop app + VS Code if you don’t have them already.

  2. Install this extension (link starts a download fyi), open VS Code, hit CMD + Shift + P, and type “Extensions: Install from VSIX” (official explainer here).

  3. Select “Work with Apps” in ChatGPT, and add the Option for VS Code and Terminal access with the “+” next to both.

To stop sharing your editor and terminal with GPT, just click Stop.

Once this is set up, ChatGPT sees everything in your open editor panes + the last 200 lines of your terminal. You can even highlight specific sections to focus GPT’s attention, just like you would with a human programming partner.

From here, ask ChatGPT to guide you as you write the code for your app (or write the code for you), then troubleshoot things for you in real-time.
