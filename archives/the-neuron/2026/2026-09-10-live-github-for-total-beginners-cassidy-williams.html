Welcome, humans.

GitHub for TOTAL beginners, LIVE now

AI can build you an app before you’ve learned what a repo, branch, or pull request is. Which is great, right up until somebody tells you to “push it to GitHub” and you realize those words apparently have meanings.

So we’re LIVE right now with Cassidy Williams, GitHub’s Senior Director of Developer Advocacy, for a GitHub crash course built specifically for people who did not come up as developers.

Why Cassidy? She’s spent her career doing the rare combination of building software and making technical ideas actually understandable. Before GitHub, she worked across companies including Amazon, CodePen, Netlify, Venmo, and Contenda, and she’s also a longtime open-source builder, speaker, startup advisor, and teacher. Her whole thing is making tech feel less intimidating, which is pretty much exactly who we wanted for this.

We’re starting from zero

  • What GitHub actually is and why you’d use it

  • Repos, branches, pushing, pulling, merging, cloning, and forking

  • How to connect AI coding agents to GitHub

  • How to safely push and merge code

  • Worktrees, GitHub Actions, key management, deployment, and more

Corey and Grant will be asking the “okay, but what does that actually mean?” questions, plus we’ll take questions from the live chat.

The goal: get you from “AI built me an app... now what?” to actually understanding how to manage, collaborate on, and safely ship your code.
