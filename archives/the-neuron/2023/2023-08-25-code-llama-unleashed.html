Meta’s New “Code LLaMA” Codes As Well As GPT-3.5.

Meta unveiled its ChatGPT coding competitor: Code Llama (built atop Llama 2)! It’s available in three flavors and three sizes (7B, 13B, & 43B).

Like ChatGPT, Code Llama writes and edits code from text prompts. Here’s how Code Llama stacks up on the well-known coding test HumanEval Benchmark:

  1. ChatGPT-4 — 67.0.

  2. CodeLlama-python — 53.7

  3. ChatGPT-3.5 — 48.1

Code Llama crushes Google’s PaLM, Codex, and other open-source models.

Some quick insights on the model (non-technical folks ... don't you dare think about skipping this!):

  • It’s open-source, which means anyone can see, use, and build on the model as if it were legos. Request access here.

  • Can run locally on the 7B model. In layman’s terms, it can run on your laptop without a cloud API & your data stays private (use llama.cpp).

  • Good for autocompletion and small code snippets (on par with Github Copilot).

  • 100k token context limit, but retrieval falters after 16k tokens, which means Code Llama can manage ~10,000 lines of code.

  • Worse than ChatGPT-4 in most ways, but more budget-friendly.

How To Get ChatGPT To “Talk” Like Your Brand.

Zapier has been churning out hundreds of articles every month … and they all sound exactly like Zapier.

Their secret? Uploading style guides to a chatbot.

Here’s the secret sauce for replicating Zapier’s success with everything from press releases to social posts:

First: write your brand’s style guide (tutorial). Must haves:

  • Company’s values and missions.

  • Brand’s voice and tone.

  • Who you're speaking to.

  • Must-follow grammar rules.

  • 10+ examples of great content (for each content category).

Second: upload your style guide to ChatGPT custom instructions:

  1. Go to ChatGPT,

  2. Custom instructions

  3. Answer box #1 with everything brand-related

  4. Answer box #2 with everything writing-related.

  5. Toggle on “Enable for new chats”.

  6. Save it all up.

You can now instruct ChatGPT to write something fresh or feed it a content draft to finesse in your voice.
