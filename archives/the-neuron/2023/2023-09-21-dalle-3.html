DALL·E 3 Is Here & It’s Darn Impressive.

OpenAI previewed v3 of its image generator DALL·E yesterday. ChatGPT Plus and Enterprise customers are set to access the API in a few weeks.

We haven’t covered DALL·E in a minute (it used to be bad), but this upgraded version actually creates images on par with Midjourney and Stable Diffusion (see for yourself with these examples).

Three very important takeaways from this update:

  1. DALL·E can render text, which all the other popular image generators struggle with.

  2. DALL·E’s big plus is that it doesn’t require elaborate prompt engineering. All it needs is simple descriptions of what you want.

  3. DALL·E will be integrated within ChatGPT, a big advantage over using Midjourney in Discord. BTW, are you thinking what I’m thinking?
